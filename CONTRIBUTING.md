# Contributing

Thank you for helping improve LandWard.

1. Discuss substantial changes in an issue before implementation.
2. Keep changes focused and include tests for behavior.
3. Run `./gradlew build` before opening a pull request.
4. Do not copy source code from other claim plugins or projects.
5. Contributions are submitted under the repository's GPL-3.0 license.

Translations should preserve placeholders exactly and update `en_US.yml` first when adding a new message key.
