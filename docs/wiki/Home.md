# LandWard

<p align="center">
  <img src="https://raw.githubusercontent.com/DEVKruidenier/LandWard.wiki/master/images/landward-logo.png" width="170" alt="LandWard shield, chunk grid and compass emblem">

> **Simple chunk claims. Reliable survival protection.**

LandWard is an open-source Paper plugin by [DEVKruidenier](https://github.com/DEVKruidenier) for survival servers that want claims to feel obvious: create a land, open the map, and click the adjacent chunk you want to protect.

| Built for players | Built for administrators |
| --- | --- |
| Native Minecraft GUI, no claim tool | Separate Safe Zones for spawn and server areas |
| One owned land, membership in many lands | SQLite and MySQL/MariaDB with verified migration |
| Member, PvP, mobs and interaction settings | WorldGuard, map, economy and analytics integrations |

## Start here
