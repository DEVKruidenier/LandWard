# Commands

All player commands begin with `/claim`.

| Command | Description |
| --- | --- |
| `/claim` | Claim the current chunk. Players without a land are told to create one first. |
| `/claim help` | Show command help. |
| `/claim create <name>` | Create the player's land and claim the current chunk. A player can own one land. |
| `/claim claim` | Compatibility form of `/claim`; it claims the current chunk too. |
| `/claim unclaim` | Release the current chunk. The first (and only remaining) chunk cannot be released. |
| `/claim info` | Show information about the current chunk. |
| `/claim list` | Open the nearby chunk map. |
| `/claim menu` | Open the land-management GUI. |
| `/claim add <player>` | Add an online player as a member. |
| `/claim remove <player>` | Remove an online member. |
| `/claim rights <player> <build\|containers\|entities> <on\|off>` | Change one member permission. |

Only the land owner can add members, remove members or change rights. Members may belong to multiple lands.
