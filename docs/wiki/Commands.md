# Commands

All player commands begin with `/land`.

| Command | Description |
| --- | --- |
| `/land` or `/land help` | Show command help. |
| `/land create <name>` | Create the player's land and claim the current chunk. A player can own one land. |
| `/land claim` | Claim the current chunk for the player's land. |
| `/land unclaim` | Release the current chunk. The first (and only remaining) chunk cannot be released. |
| `/land info` | Show information about the current chunk. |
| `/land list` | Open the nearby chunk map. |
| `/land menu` | Alias for the chunk map while the management screen is being completed. |
| `/land add <player>` | Add an online player as a member. |
| `/land remove <player>` | Remove an online member. |
| `/land rights <player> <build\|containers\|entities> <on\|off>` | Change one member permission. |

Only the land owner can add members, remove members or change rights. Members may belong to multiple lands.
