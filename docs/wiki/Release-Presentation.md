# Release Presentation

Before LandWard's first public release, the project will receive its visual release assets from a running, fully tested server.

## Required assets

- A square LandWard project icon for GitHub, Modrinth, PaperMC and SpigotMC.
- A clean claim-map screenshot showing the green, grey and red chunk states.
- A land-management screenshot showing members and their individual rights.
- A protection screenshot or short GIF demonstrating a denied interaction in another player's claim.
- A concise feature image for every public platform page.

## Publication checklist

1. Verify the final plugin JAR on the local Paper test server.
2. Capture screenshots without debug text or development placeholders.
3. Add alt text and captions to this wiki.
4. Publish the exact same verified JAR and release notes to Modrinth, PaperMC and SpigotMC.
5. Use fresh, minimum-scope API tokens only at release time.

The screenshots are intentionally postponed until the complete GUI, localization and map integrations are present, so every image reflects the released product.
