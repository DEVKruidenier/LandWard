# Translations

Every message, GUI title, item label, lore line, command response, and administrator notification must come from a locale file in `src/main/resources/lang/`.

Bundled locales:

- English (`en_US`) — fallback
- Dutch (`nl_NL`)
- German (`de_DE`)
- French (`fr_FR`)
- Spanish (`es_ES`)
- Brazilian Portuguese (`pt_BR`)
- Italian (`it_IT`)
- Polish (`pl_PL`)
- Turkish (`tr_TR`)
- Russian (`ru_RU`)
- Simplified Chinese (`zh_CN`)
- Japanese (`ja_JP`)
- Korean (`ko_KR`)

Translations may be edited in the plugin data folder. Missing keys fall back to English.
